# Meu ambiente no Manjaro KDE

Uso Manjaro com KDE Plasma como sistema principal. Essa combinação me oferece um ambiente Linux atualizado, personalizável e confortável para estudar programação.

## Ferramentas principais

Meu ambiente de desenvolvimento inclui:

* **JDK** para compilar e executar aplicações Java
* **Maven** para gerenciar dependências e builds
* **IntelliJ IDEA** ou outro editor com suporte a Java
* **Git e GitHub** para versionamento de código
* **Docker** para executar aplicações e serviços isolados
* **Konsole** para trabalhar com comandos e automações

## Conferindo o Java

No terminal, posso verificar a versão instalada com:

```bash
java --version
javac --version
```

No Manjaro, os ambientes Java instalados também podem ser consultados com:

```bash
archlinux-java status
```

## Por que Linux?

Além da liberdade de personalização, Linux aproxima meu ambiente local dos servidores onde aplicações backend costumam ser executadas. O terminal, o gerenciamento de pacotes e as ferramentas de automação fazem parte do meu processo de aprendizado.
